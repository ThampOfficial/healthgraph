# Health Checkup Book · สมุดผลตรวจสุขภาพ

Yearly health checkup comparison with trend charts (English / Thai).

- The app runs as a Google Apps Script web app; data lives in a private Google Sheet (not in this repo).
- `index.html` (GitHub Pages) just redirects to the Apps Script web app.
- `apps-script/Code.gs` and `apps-script/Index.html` are the Apps Script source. To redeploy: open the Sheet → Extensions → Apps Script, paste both files, Deploy → Web app (Execute as: Me, Access: Only myself).

For tracking trends only — not medical advice.
